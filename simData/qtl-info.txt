Bpair = chromosomal position in basepair
Freq = frequency of allele 1
Rep = 1 if QTL is represented (genotyped) in microarray
QTL = qtl number as it appeared in QTL-MAS 2010 printed material
QTLBT = 1 if QTL has pleiotropic effect (affect also binary trait) 
      = 0 if QTL affects only quantitative trait
Add = additive effect: half the difference between homozygote means, Add = [ M(11) - M(22) ] / 2
