QTL-MAS 2010 Workshop, Poznan, Poland.
The file 'genotypes-true-phase.txt' cointains QTL-MAS2010 simulated
SNP data for 3226 individuals and 1031 markers in the following format: 
Col1   Id
Col2   Marker 1  paternal allele
Col3   Marker 1  maternal allele
col4   Marker 2  paternal allele
Col5   Marker 2  maternal allele
etc.

Note, ten of the 1031 SNPs are functional mutations with an effect on
quantitative trait. Two of the 10 SNP have also effect on binary trait.
Other 27 QTLs are not included in the 'genotypes-true-phase.txt' file.
The phased genotypes for all 37 QTLs can be found in file
'qtl-genotypes.txt' and information on QTL positions can be found in
file 'qtl-info.txt'.
